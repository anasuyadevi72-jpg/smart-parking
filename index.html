DATA STRUCTURES PROJECT

Smart Parking
using Hashing

A web-based simulation demonstrating how hashing techniques can efficiently manage parking allocation, collision resolution and vehicle searching.

CORE FORMULA
h(k) = k mod 11
Example: 1021 mod 11 = 9
01

Objective

Design a smart parking system where vehicle registration numbers are converted into hash keys and mapped efficiently to parking slots.

02

Why Hashing?

Hashing provides fast average-case insertion, searching and deletion by directly mapping a vehicle key to a parking location.

03

Collision Handling

When multiple vehicles map to the same slot, collision-resolution algorithms find the next suitable position.

IMPLEMENTED TECHNIQUES

Five collision strategies

01 Linear Probing Check consecutive slots.
02 Quadratic Probing Use increasing quadratic offsets.
03 Double Hashing Use a second hash function.
04 Separate Chaining Store collisions in linked buckets.
05 Rehashing Expand the table and insert again.
