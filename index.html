ACADEMIC PROJECT

About ParkHash

A smart parking system based on hashing and collision handling.

PROJECT OBJECTIVE

Demonstrating data structures through real-world parking management.

ParkHash uses hashing techniques to efficiently assign vehicles to parking slots while demonstrating collision resolution strategies.

01

Linear Probing

Checks consecutive slots when a collision occurs.

02

Quadratic Probing

Uses quadratic jumps to find another available slot.

03

Double Hashing

Uses a second hash function for collision resolution.

04

Separate Chaining

Stores multiple collided vehicles in a chain.

05

Rehashing

Uses a larger table when more capacity is required.
